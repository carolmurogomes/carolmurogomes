## 📊 Featured Projects

### 📚 Les Misérables — Literary Data Analytics

An interdisciplinary data analytics project inspired by Victor Hugo's *Les Misérables*, combining literature, geography, history, and emotional analysis.

Developed a curated relational dataset using AI-assisted data extraction, exploring character appearances, geographic locations, historical events, and emotional patterns throughout the novel.

The project integrates data modeling, interactive visualizations, geographic mapping, and narrative storytelling to reveal new perspectives on a literary classic.

**Tools:** Python • SQL • Data Modeling • Looker Studio • Data Visualization • AI-Assisted Data Extraction

**Highlights:**
- Curated dataset featuring 58 literary characters.
- Geographic analysis of character journeys and historical locations.
- Emotional analysis of the novel's vocabulary.
- Interactive dashboards and visual storytelling.
- Presented at Le Wagon's Demo Day in October 2026.

### 💰 WEG — DRE Financial Analysis & Business Intelligence

A financial analytics project focused on the Income Statement (DRE) of WEG S.A., using financial data from 2023 to 2025.

Developed a Power BI solution integrating data transformation, dimensional modeling, DAX measures, financial performance indicators, and interactive dashboards.

The project includes three analytical components:

- **Management Income Statement:** Financial results, account hierarchy, and horizontal and vertical analysis.
- **Financial Analysis:** Revenue growth, profitability margins, CAGR, and financial performance indicators.
- **Financial Scenario Simulator:** Interactive What-if parameters to evaluate the potential impact of changes in revenue, costs, expenses, financial results, and taxes.

**Tools:** Power BI • Power Query • DAX • Dimensional Modeling • Financial Analysis

**Repository:** [WEG Financial Analysis](https://github.com/carolmurogomes/weg-financial-analysis)
